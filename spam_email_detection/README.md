# 📧 Spam Email Detection using NLP

## Overview

This project classifies emails/messages as Spam or Ham (Not Spam) using Natural Language Processing (NLP) and Machine Learning.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- Jupyter Notebook

## Concepts Used

- NLP (Natural Language Processing)
- TF-IDF Vectorization
- Naive Bayes Classification
- Train-Test Split
- Model Evaluation

## Workflow

Email Text
→ TF-IDF Vectorization
→ Naive Bayes Model
→ Spam / Ham Prediction

## Sample Predictions

- "Free lottery ticket claim reward now" → Spam
- "Project meeting tomorrow at 10 AM" → Ham

## Learning Outcomes

- Text Preprocessing
- NLP Fundamentals
- Feature Extraction using TF-IDF
- Spam Classification
- Machine Learning Workflow
